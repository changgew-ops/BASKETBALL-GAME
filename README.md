# BASKETBALL-GAME

한국프로농구(KBL) 구단 단장(GM) 시뮬레이션과, 에이전트들이 일하는 픽셀 오피스입니다.
두 파일 모두 서버 없이 **더블클릭만으로** 브라우저에서 열립니다.

| 파일 | 내용 |
|---|---|
| [`game.html`](game.html) | **프로농구 단장 게임** — 카드를 모으고 키우며 시즌을 치르는 싱글 플레이 GM 게임 |
| [`office.html`](office.html) | **에이전트 오피스** — 작업하는 에이전트들이 움직이는 픽셀 오피스 |

## 문서

| 문서 | 내용 |
|---|---|
| [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md) | 게임 기획서 (규칙·시스템·화면의 기준 문서) |
| [`docs/BALANCE.md`](docs/BALANCE.md) | 밸런스 설계와 수치 |
| [`docs/QA.md`](docs/QA.md) | 검증·테스트 항목 |
| [`docs/OFFICE.md`](docs/OFFICE.md) | 에이전트 오피스 설명 (동작 규칙, 층 구성, 게시 방법) |

## 참고

- 게임 저장은 브라우저 안에 남습니다. 같은 파일을 같은 브라우저로 열어야 이어서 할 수 있습니다.
- 선수 얼굴 사진(페이스팩)은 용량과 권리 문제로 이 저장소에 없습니다. 없으면 기본 아바타로 표시됩니다.
- 문서 안에서 언급하는 소스 코드·데이터 폴더(`src/`, `web/`, `data/`, `tools/` 등)는 개발 저장소에 있으며, 이 저장소에는 단일 파일 빌드(`game.html`, `office.html`)만 올라와 있습니다.
